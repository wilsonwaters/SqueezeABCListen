# SqueezeABCListen

An unofficial [Lyrion Music Server](https://lyrion.org/) (formerly Logitech Media Server / Squeezebox Server) plugin for **ABC listen** — browse ABC radio stations, programs and episodes with artwork and descriptions, and play live or on-demand audio on your Squeezebox players.

> Status: in development. See `ai-state/PROGRESS.md` for the current state of the project.

Not affiliated with or endorsed by the Australian Broadcasting Corporation.
