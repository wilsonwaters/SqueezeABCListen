# Strings for the ABC listen plugin (English only).
# Format: a TOKEN line, then one line per language: <TAB>EN<TAB>text
# Each task edits only inside its own section below (new tokens are appended to the owner's section).
# Sections are in wave order: F1 | F2 F3 R1 M1 | L1 O1 O2 | L2 L5 O3 D1 D3 M2 | L3 L4 O4 D2 | R2 | R3, then
# later tasks appended in merge order (D4 D7 D5 L6).
# Station names (triple j, Radio National, ...) are ABC proper nouns and are not string tokens.

PLUGIN_ABCLISTEN_LIVE_QUALITY
	EN	Live stream quality

# Reworded by L6 (the HLS option)
PLUGIN_ABCLISTEN_LIVE_QUALITY_DESC
	EN	Standard plays ABC's Icecast streams, which work everywhere. High quality (HLS) plays ABC's HLS streams, as ABC's website does (192 kbps AAC on music stations), and also lists the stations ABC streams only in HLS. ABC mediahub AAC tries ABC's mediahub stream. Both higher-quality options fall back to the standard stream when theirs can't be played.

PLUGIN_ABCLISTEN_LIVE_QUALITY_STANDARD
	EN	Standard: 56 kbps, works everywhere

PLUGIN_ABCLISTEN_LIVE_QUALITY_MEDIAHUB
	EN	ABC mediahub AAC: higher quality, may only work in Australia
